# GetWellDosed.com

Official Phase 1 website for Well Dosed.

## Brand direction
**High Standards. Better Ingredients.**

## GitHub Pages
The site is static and ready for GitHub Pages. Keep `index.html`, `styles.css`, `script.js` and the `assets` folder at the repository root.

## Notes
- Rewards are intentionally reserved for Phase 2.
- No "Get to know your dose" section is included.
- The current retail locator is a coming-soon section.
- Product and ingredient claims should be updated to match the final tested and approved commercial formulation before launch.
- Final cannabis advertising disclosures, warnings and licensee information should be reviewed for Nevada compliance before commercial launch.
